# nginxproxymanager

The Nginx Proxy Manager provider is used to manage instances of [Nginx Proxy Manager](https://nginxproxymanager.com) via the API.

**This provider has been developed as part of a learning project, and is not suitable for production purposes.**

## Example Usage 

```terraform
provider "nginxproxymanager" {
  host     = "localhost:81"
  username = "admin@example.com"
  password = "changeme"
  secure   = false
}

# Or with a token, e.g for a user with two-factor authentication. The token
# can also be set with NGINXPROXYMANAGER_TOKEN, and the other settings with
# NGINXPROXYMANAGER_HOST, NGINXPROXYMANAGER_USERNAME, NGINXPROXYMANAGER_PASSWORD
# and NGINXPROXYMANAGER_SECURE.
provider "nginxproxymanager" {
  alias = "token"
  host  = "npm.example.com"
  token = var.npm_token
}

variable "npm_token" {
  type      = string
  sensitive = true
}
```

## Schema

### Optional

- `host` (String) Hostname and port of Nginx Proxy Manager, e.g `npm.example.com:81`. Can also be set with `NGINXPROXYMANAGER_HOST`.
- `password` (String, Sensitive) Password of the user to authenticate as. Can also be set with `NGINXPROXYMANAGER_PASSWORD`.
- `request_timeout` (Number) Timeout in seconds for a single API request. Defaults to 1200, as NPM answers certificate requests only once Letsencrypt has issued the certificate.
- `secure` (Boolean) Whether to use a secure (https) connection for API requests. Can also be set with `NGINXPROXYMANAGER_SECURE`.
- `token` (String, Sensitive) An API token to use instead of logging in, e.g for a user with two-factor authentication. A long-lived one can be requested with `GET /api/tokens?expiry=1y` while logged in. The token is refreshed while it's valid, and `username`/`password` are used to log in again if it expires. Can also be set with `NGINXPROXYMANAGER_TOKEN`.
- `username` (String) Email address of the user to authenticate as. Can also be set with `NGINXPROXYMANAGER_USERNAME`.
